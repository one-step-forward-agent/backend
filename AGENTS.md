# Backend instructions
When available, read `../AGENTS.md` and `../codex-setup/commands.md` for workspace rules and safe test setup.

- Use async SQLAlchemy `AsyncSession` from `app/core/database.py`; follow the surrounding service transaction boundaries. Do not introduce blocking I/O into async routes. Put domain logic in `app/services`, external adapters in top-level `services` or `app/services/integrations`, and request/response validation in Pydantic schemas.
- Inspect `app/main.py` router registration, `app/api/deps.py` and existing domain tests before adding endpoints. Enforce object ownership, team role or admin checks on reads and writes. Internal bot endpoints must keep `require_bot` protection and resolve the linked user.
- `app/models/models.py` owns SQLAlchemy models. Add an Alembic revision for schema changes; inspect `alembic heads` and the preceding revision, not a guessed numeric filename. Do not rewrite applied revisions. Review constraints, nullable transitions, backfills, downgrade consequences and encrypted columns manually after autogeneration.
- Personal fields use `app/core/dataenc.py`; integration secrets use `app/core/crypto.py`. Preserve encryption type decorators, stable lookup keys and key compatibility. No production re-encryption, admin grants or decrypted ratings exports as verification.
- Preserve assistant draft confirmation, send-draft confirmation, recurrence, all-day/multiday semantics, timezone handling and notification claim/ack idempotency. Tests exist for each domain; use them rather than introducing a parallel harness.
- From this directory, use a Python 3.12 virtual environment: `python -m pip install -r requirements-dev.txt`; `python -m uvicorn app.main:app --reload`; `python -m alembic heads`; `python -m pytest tests/test_dates.py -q`. Full pytest and migrations require a verified disposable PostgreSQL database; see the workspace command guide.
- `tests/conftest.py` imports the app and sets defaults with `setdefault`: inherited production environment can override them. Tests do not isolate the database by transaction rollback. Mock LLM/calendar/email services; inspect selected tests for external calls.
- App startup can grant configured admin access and start calendar sync. Docker startup additionally applies migrations. Production safety validation must remain enabled. Use `app/core/errors.py` and structured, sanitized logging rather than returning internal exceptions.
